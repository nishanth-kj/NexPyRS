# Universal Coding Standards

1. **Readability First**: Code is read more often than it is written. Use descriptive variable and function names.
2. **DRY (Don't Repeat Yourself)**: Extract reusable logic into functions or classes.
3. **Error Handling**: Do not swallow exceptions silently. Log them or handle them appropriately.
4. **Documentation**: Public APIs, complex algorithms, and non-obvious logic must be documented with comments or docstrings.
5. **Formatting**: Always format code using the standard formatter for the language (e.g., Prettier, Black, Rustfmt) before finalizing.
