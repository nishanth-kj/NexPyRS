# Skill: Refactor Code

When asked to refactor code:
1. Understand the original intent and logic of the code.
2. Identify areas for improvement (e.g., cyclomatic complexity, deeply nested loops, repeated logic).
3. Extract methods and apply design patterns where appropriate.
4. Ensure that the original functionality remains exactly the same.
5. Do not alter any public API signatures unless explicitly requested.
