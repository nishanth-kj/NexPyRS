# Skill: Generate Tests

When asked to generate tests, follow these steps:
1. Identify the input module or function.
2. Analyze the different execution paths, including edge cases and error states.
3. Write isolated unit tests for each path using the standard testing framework for the language.
4. Include mock objects where necessary to isolate the logic.
